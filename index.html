Выберите, что отправлять через прокси. Конструктор создаст совместимый профиль INCY и ссылку для импорта.

01

Режим маршрутизации

Что делать с трафиком, для которого нет отдельного правила.

Предустановка добавит популярные зарубежные сервисы в правила прокси. Наборы ниже можно изменить.

Белые списки РКН · NIDOX

Загружаем актуальный список…

Используется профиль NIDOX: только его домены и IP идут напрямую. Для чистого автообновляемого профиля откройте ссылку импорта INCY.

02

Готовые наборы правил

Каждое нажатие: выкл → через прокси → напрямую → выкл.

Выбирайте сервисы как готовые группы доменов — без ручного JSON.

Выбор режима сверху применяет собственную предустановку и сбрасывает наборы. Ручное изменение чипа создаёт индивидуальную настройку.

03

Свои правила

По одной записи в строке: домен, IP или подсеть CIDR.

Исключения и блокировка
04

DNS и списки

Используются только документированные поля INCY.

Геофайлы и белые списки РКН
INCY поддерживает URL geoip.dat и geosite.dat, но не задаёт отдельный «формат списка РКН». Указывайте только проверенный совместимый геофайл; теги в правилах должны быть в нём определены.
